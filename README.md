# 치이카와 오피스

업무를 지시하면 치이카와 팀이 회의실에 모이고, 자료실·탕비실·자리를 오가며 일을 끝내는 사무실 시뮬레이션이에요.

- **바로 보기**: GitHub Pages를 켜면 `https://onyoupado.github.io/Chiikawa-office/` 에서 열 수 있어요.
- **데모 모드**: GitHub에서 열면 Claude를 부르지 않아요. 토큰을 쓰지 않고, 예시 형식의 결과물로 흐름만 보여줘요.
- **실제 처리 모드**: claude.ai 아티팩트로 열면 업무 하나에 Claude를 한 번만 불러 실제 결과물을 만들어요.

파일 하나(`index.html`)로 되어 있고, 별도 설치나 빌드 없이 브라우저에서 바로 열려요.

> 팬이 만든 비공식 프로젝트예요. 치이카와 캐릭터의 권리는 원작자 나가노에게 있어요.
