# 치이카와 오피스

업무를 지시하면 치이카와 팀이 회의실에 모이고, 자료실·탕비실·자리를 오가며 일을 끝내는 사무실 시뮬레이션이에요.
랏코 팀장·치이카와·하치와레·우사기가 일을 하고, 모몽가·쿠리만쥬·시사·카니도 사무실을 돌아다녀요.
사무실은 3D 모형처럼 보이고, 쉬는 시간에는 엘리베이터를 타고 위층으로 놀러 가요.
- **2F 기숙사**: 각자 침대에서 낮잠, 샤워실, 공용 거실(주방·TV)
- **3F 취미층**: 취미방(게임·이젤·피아노·보드게임), 영화관(대형 스크린·계단식 좌석·팝콘 기계), 외부 테라스(파라솔 테이블·선베드·바비큐 그릴·화단)

지도 위 층 버튼으로 1F·2F·3F를 바꿔 볼 수 있어요.

**바로 보기:** https://onyoupado.github.io/Chiikawa-office/ · claude.ai 아티팩트: https://claude.ai/artifact/U4fT3Hf2L8Up2zPpXpix2v

## 3D 버전 (베타)

**링크:** https://onyoupado.github.io/Chiikawa-office/3d.html · claude.ai 아티팩트: https://claude.ai/artifact/9PudZt5Z3E3N53G8JZsaF5 (아티팩트 안에서는 키 없이 Claude 대화·업무가 동작해요. 공유 설정에 따라 열람 가능 여부가 달라요)

Three.js로 만든 진짜 3D 건물이에요. 1F 사무실, 2F 기숙사, 3F 취미층(취미방·영화관·외부 테라스)이 있어요.

- **조작**: 한 손가락으로 끌면 회전, 두 손가락으로 확대·이동해요. 층 버튼이나 "건물 전체"로 볼 층을 골라요.
- **층 이동**: 캐릭터는 엘리베이터와 왕복 에스컬레이터(1↔2층, 2↔3층에 올라가는 것과 내려가는 것 각각)로 층을 오가요.
- **사물 상호작용**: 캐릭터를 고른 뒤 커피머신·냉장고·침대·피아노·게임기·영화관 좌석·선베드·바비큐 그릴 같은 가구를 누르면 그 자리로 가서 행동해요. 마우스를 올리면 이름과 할 수 있는 행동이 보이고, 행동이 여럿이면(침대: 낮잠/잠자기) 작은 메뉴가 떠요. 고장 난 커피머신이나 정전 때 쓸 수 없는 물건은 이유를 알려 줘요. 상태창의 **주변 사물** 버튼으로 키보드만으로도 똑같이 할 수 있어요. 산 가구(오락기·안마의자·푸딩 자판기)도 바로 쓸 수 있어요.
- **명령**: 캐릭터를 누르고 바닥을 누르면 걸어가요. "우사기 테라스로 가", "하치와레 노래 불러", "모두 기숙사로 가"처럼 글로 써도 돼요. 명령 해석에는 토큰이 들지 않아요.
- **욕구와 감정**: 캐릭터마다 욕구 6가지가 있고, 부족하면 스스로 채워요. 머리 위 다이아몬드 색과 이모지로 기분을 보여 줘요.
- **하루 흐름**: 게임 시계가 흘러요. 아침 준비, 업무, 점심, 퇴근 후 취미, 밤에는 기숙사에서 잠을 자요. 조명도 낮·노을·밤으로 바뀌어요. "시간 ×1/×4/×12"로 빠르게 돌릴 수 있어요.
- **관계**: 같이 수다를 떨고 놀수록 "아는 사이 → 친구 → 절친 → 단짝"으로 가까워져요. 친한 친구와 더 자주 어울려요.
- **고유 특성**: 성격, 욕구가 줄어드는 속도, 좋아하는 행동, 전용 행동이 캐릭터마다 달라요.
  - 치이카와: 풀뽑기 자격증 공부
  - 하치와레: 노래 부르기 (주변 친구들의 재미가 올라요)
  - 우사기: 우라! 외치기
  - 랏코: 검술 수련
  - 모몽가: 애교 부리기
  - 쿠리만쥬: 한 잔 하기
  - 시사: 주방 일 연습
  - 카니: 책 정리하기
- **상태창**: 레벨, 경험치, 기분, 욕구, 기술 5가지, 관계, 행동 버튼, 대화하기가 있어요.
- **대화**: 캐릭터와 말을 주고받을 수 있어요. Claude가 연결돼 있으면 캐릭터 말투로 대답하고, "같이 커피 마시러 가자"처럼 하자고 하면 실제로 해요. 연결이 없으면 미리 정해 둔 대사로 대답해요(토큰 0).
- **과업과 성장**: 과업을 깨면 오피스 레벨과 코인이 올라요. 행동할수록 캐릭터 레벨과 기술 레벨이 올라요.
- **상점과 꾸미기**: 코인으로 가구(화분·무드등·오락기·안마의자·푸딩 자판기·분수 등)를 사서 원하는 바닥에 놓아요. 고급 커피머신으로 업그레이드할 수 있고, 캐릭터에게 모자(리본·고깔·꽃핀·요리사 모자·왕관)를 씌울 수 있어요.
- **바깥 손님**: 택배 기사님, 배달 라이더, 외부 손님이 인도(손님은 버스 정류장)에서 정문을 지나 1층 로비로 들어와요. 친구가 마중 나가서 택배를 받고, 배달 음식은 탕비실에 차려 다 같이 먹고, 외부 손님은 랏코가 회의실로 안내해 미팅해요. 알림의 버튼을 누르지 않아도 잠시 뒤 알아서 맞이해요. 2D는 1층 복도 오른쪽 끝이 정문이에요.
- **랜덤 이벤트**: 케이크, 정전, 커피머신 고장, 테라스에 나타난 수상한 녀석 토벌도 있어요.
- **층 표시**: 지금 보는 층에 있는 캐릭터만 보여요. 에스컬레이터를 타는 중이면 출발·도착 층 모두에서, "건물 전체"에서는 모두 보여요.
- **터미널 실제 작업 동기화**: Claude Code가 이 저장소에서 실제로 일하는 동안, 맡은 캐릭터가 자리에서 그 일을 하고 화면 위쪽에 "터미널 작업 중" 띠와 단계별 진행이 보여요. 아래 '터미널 작업 동기화'를 참고하세요.
- **업무 지시**: 2D처럼 Claude에게 업무를 맡기면 팀이 회의하고 자리에서 일한 뒤 결과물을 보여 줘요.
- **기타**: 효과음과 배경음(직접 합성한 소리), 사진 찍기(PNG 저장)가 있어요.
- **저장**: 진행 상황은 각자 브라우저에 자동 저장돼요.
- **확대·축소와 3D 조작 켜기/끄기**: 두 손가락이나 마우스 휠, 또는 화면 아래 ＋/－ 버튼으로 확대·축소해요. "3D 조작"을 끄면 화면 위에서 손가락으로 페이지를 스크롤할 수 있어요(다시 켜면 회전·확대가 돼요).
- **화질**: 화면 아래 "화질" 버튼으로 가볍게 / 보통 / 고화질을 고를 수 있어요. 휴대폰은 처음에 '보통'(가벼운 조명, 낮은 해상도, 초당 40장, 그림자 끔)으로 시작해요. 그래도 버벅이면 '가볍게'를 써 보세요.
- **에이전트 회의·개발 현황**: 캐릭터마다 개발팀 역할이 있어요(랏코 팀장, 하치와레 프론트엔드, 치이카와 디자인, 우사기 QA, 시사 로직, 쿠리만쥬 배포, 모몽가 문서, 카니 리뷰). "작업 다시 보기"를 누르면 이 프로젝트에서 실제로 한 작업(`3d/worklog.js`)을 회의 → 개발 → 테스트 → 배포 순서로 재현해요. 주제를 넣고 "회의 열기"를 누르면 회의를 해서 할 일을 정하고 일하러 가요. 업무 시간에는 가끔 알아서 아침 회의도 해요.
- **카메라 시점**: 기본, 왼쪽, 오른쪽, 뒤쪽, 눈높이, 위에서, 거리에서 보기, 캐릭터 따라가기, 자동 회전을 고를 수 있어요.
- **건물과 거리**: 유리 통창 건물(층을 볼 때는 앞쪽 유리를 숨겨요), 옥상 간판, 인도와 가로수, 가로등(밤에 켜져요), 도로를 달리는 차와 버스, 버스 정류장, 지하철 입구가 있어요.

## 실제로 일하게 하려면 (Claude 연결)

처음 열면 **데모 모드**예요. 캐릭터는 다 움직이지만 결과물은 정해진 예시로 나오고, 아무것도 밖으로 보내지 않아요.
보안을 위해 **브라우저에 API 키를 넣는 기능은 없앴어요** (예전 버전이 저장한 `chiikawa-office-apikey` 값은 열 때 자동으로 지워요).

- **프롬프트 복사 (서버 없이)**: 업무를 쓰고 **프롬프트 복사**를 눌러 Claude에 붙여 넣은 뒤, 받은 답을 **답 붙여 넣기**에 넣으면 결과물이 정리돼요.
- **claude.ai 아티팩트 안에서 열기**: 키 없이 내 claude.ai 사용량으로 바로 동작해요.
- **직접 운영하는 서버 프록시**: `server/` 폴더의 예시를 내 서버에서 돌리고 `config.js`에 주소만 적어요. 관리자에게 받은 접속 코드를 넣으면 연결돼요 (접속 코드는 탭 메모리에만 있고 저장되지 않아요). 자세한 내용은 [server/README.md](server/README.md).

**이 브라우저에 저장되는 것**: 2D 업무 기록, 3D 진행 상황과 대화 기록, 화질 설정. **저장하지 않는 것**: API 키, 접속 코드. 화면의 **업무 기록 지우기 / 대화 기록 지우기 / 로컬 기록 모두 삭제**로 언제든 지울 수 있어요.

## 터미널 작업 동기화

작업 상태는 `tools/live.mjs`가 저장소의 **`live` 브랜치**에 `status.json` 하나로 올려요 (main 기록과 Pages 배포에는 영향이 없어요).

```bash
node tools/live.mjs start "작업 제목" "요청 한 줄"
node tools/live.mjs step hachiware "화면 고치기" doing    # todo | doing | done
node tools/live.mjs done
```

- GitHub Pages 버전은 GitHub API로 75초마다 확인해요 (GitHub의 비로그인 요청 한도는 IP당 시간당 60회).
- claude.ai 아티팩트 버전은 아티팩트 저장소(`live/status` 문서)를 실시간으로 읽어요. 아티팩트 쪽은 Claude가 작업하면서 직접 기록해요.
- 마지막 소식이 45분보다 오래되면 끝난 것으로 봐요.
- 이 동기화는 Claude가 단계마다 알려 주는 방식이라, 타자 하나하나가 실시간으로 보이지는 않아요.

## 파일 구성

빌드 없이 GitHub Pages에서 그대로 열려요 (ES 모듈 + importmap).

- `index.html`, `2d/app.js`, `2d/styles.css`: 2D 사무실
- `3d.html`, `3d/core.js`(렌더러·도우미), `3d/app.js`(월드·캐릭터·시뮬레이션·UI), `3d/commands.js`(글 명령 해석), `3d/interactions.js`(사물 등록), `3d/persistence.js`(저장 데이터 검증), `3d/quests.js`, `3d/worklog.js`
- `shared/`: 2D와 3D가 같이 쓰는 AI 연결(`ai-client.js`), 답 해석(`parse.js`), 마크다운(`markdown.js`), 저장소(`storage.js`), 활동 잠금(`activity-controller.js`), 행동 문구(`actions.js`)
- `shared/live.js`: 터미널 작업 동기화, `tools/live.mjs`: 작업 상태 올리기
- `config.js`: 서버 프록시 주소 (비워 두면 데모 모드). API 키를 넣는 곳이 아니에요.
- `server/`: 선택 서버 프록시 예시
- `tests/`: `npm test`(순수 함수 단위 시험, Node 20+), `tests/browser/`(Playwright 시나리오 시험: `2d.cjs`, `3d.cjs`, `3d-extra.cjs`. 사용법은 `helper.cjs` 맨 위)

> 팬이 만든 비영리·비공식 프로젝트예요. `img` 폴더의 캐릭터 이미지를 포함해 치이카와 캐릭터의 모든 권리는 원작자 나가노에게 있어요. 권리자가 요청하면 바로 내릴게요.
