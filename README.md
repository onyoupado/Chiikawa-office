# 치이카와 오피스

업무를 지시하면 치이카와 팀이 회의실에 모이고, 자료실·탕비실·자리를 오가며 일을 끝내는 사무실 시뮬레이션이에요.
랏코 팀장·치이카와·하치와레·우사기가 일을 하고, 모몽가·쿠리만쥬·시사·카니도 사무실을 돌아다녀요.
사무실은 3D 모형처럼 보이고, 쉬는 시간에는 엘리베이터를 타고 위층으로 놀러 가요.
- **2F 기숙사**: 각자 침대에서 낮잠, 샤워실, 공용 거실(주방·TV)
- **3F 취미층**: 취미방(게임·이젤·피아노·보드게임), 영화관(대형 스크린·계단식 좌석·팝콘 기계), 외부 테라스(파라솔 테이블·선베드·바비큐 그릴·화단)

지도 위 층 버튼으로 1F·2F·3F를 바꿔 볼 수 있어요.

**바로 보기:** https://onyoupado.github.io/Chiikawa-office/

## 3D 버전 (베타)

**링크:** https://onyoupado.github.io/Chiikawa-office/3d.html

Three.js로 만든 진짜 3D 건물이에요. 1F 사무실, 2F 기숙사, 3F 취미층(취미방·영화관·외부 테라스)이 있어요.

- **조작**: 한 손가락으로 끌면 회전, 두 손가락으로 확대·이동해요. 층 버튼이나 "건물 전체"로 볼 층을 골라요.
- **층 이동**: 캐릭터는 엘리베이터와 왕복 에스컬레이터(1↔2층, 2↔3층에 올라가는 것과 내려가는 것 각각)로 층을 오가요.
- **명령**: 캐릭터를 누르고 바닥을 누르면 걸어가요. "우사기 테라스로 가", "하치와레 노래 불러", "모두 기숙사로 가"처럼 글로 써도 돼요. 명령 해석에는 토큰이 들지 않아요.
- **욕구와 감정**: 캐릭터마다 욕구 6가지가 있고, 부족하면 스스로 채워요. 머리 위 다이아몬드 색과 이모지로 기분을 보여 줘요.
- **하루 흐름**: 게임 시계가 흘러요. 아침 준비, 업무, 점심, 퇴근 후 취미, 밤에는 기숙사에서 잠을 자요. 조명도 낮·노을·밤으로 바뀌어요. "시간 ×1/×4/×12"로 빠르게 돌릴 수 있어요.
- **관계**: 같이 수다를 떨고 놀수록 "아는 사이 → 친구 → 절친 → 단짝"으로 가까워져요. 친한 친구와 더 자주 어울려요.
- **고유 특성**: 성격, 욕구가 줄어드는 속도, 좋아하는 행동, 전용 행동이 캐릭터마다 달라요.
  - 치이카와: 풀뽑기 자격증 공부
  - 하치와레: 노래 부르기 (주변 친구들의 재미가 올라요)
  - 우사기: 우라! 외치기
  - 랏코: 검술 수련
  - 모몽가: 애교 부리기
  - 쿠리만쥬: 한 잔 하기
  - 시사: 주방 일 연습
  - 카니: 책 정리하기
- **상태창**: 레벨, 경험치, 기분, 욕구, 기술 5가지, 관계, 행동 버튼, 대화하기가 있어요.
- **대화**: 캐릭터와 말을 주고받을 수 있어요. Claude가 연결돼 있으면 캐릭터 말투로 대답하고, "같이 커피 마시러 가자"처럼 하자고 하면 실제로 해요. 연결이 없으면 미리 정해 둔 대사로 대답해요(토큰 0).
- **과업과 성장**: 과업을 깨면 오피스 레벨과 코인이 올라요. 행동할수록 캐릭터 레벨과 기술 레벨이 올라요.
- **상점과 꾸미기**: 코인으로 가구(화분·무드등·오락기·안마의자·푸딩 자판기·분수 등)를 사서 원하는 바닥에 놓아요. 고급 커피머신으로 업그레이드할 수 있고, 캐릭터에게 모자(리본·고깔·꽃핀·요리사 모자·왕관)를 씌울 수 있어요.
- **랜덤 이벤트**: 택배, 케이크, 정전, 커피머신 고장, 테라스에 나타난 수상한 녀석 토벌이 있어요.
- **업무 지시**: 2D처럼 Claude에게 업무를 맡기면 팀이 회의하고 자리에서 일한 뒤 결과물을 보여 줘요.
- **기타**: 효과음과 배경음(직접 합성한 소리), 사진 찍기(PNG 저장)가 있어요.
- **저장**: 진행 상황은 각자 브라우저에 자동 저장돼요.

## 실제로 일하게 하려면

처음 열면 **데모 모드**예요. 캐릭터는 다 움직이지만 결과물은 정해진 예시로만 나와요.

1. [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 API 키를 만들어요. (결제 수단 등록이 필요해요.)
2. 페이지의 **업무 지시서 → Claude 연결하기**를 열고 키를 넣은 뒤 **저장하고 연결**을 눌러요.
3. 오른쪽 위가 **실제 처리 모드**로 바뀌면 끝이에요.

- 키는 각자 자기 브라우저에만 저장되고 Anthropic에만 보내져요. 다른 사람에게 키를 공유하지 마세요.
- 사용료는 키 주인 계정으로 나가요. 업무 하나에 Claude를 한 번만 부르고, 생각하는 양(effort)을 낮게 설정해 토큰을 아껴요.
- 모델은 Opus 5.5(기본), Sonnet 5.5, Haiku 5.5(가장 저렴) 중에 고를 수 있어요.

파일 하나(`index.html`)와 캐릭터 이미지(`img/`)로 되어 있고, 별도 설치나 빌드 없이 브라우저에서 바로 열려요.

> 팬이 만든 비영리·비공식 프로젝트예요. `img` 폴더의 캐릭터 이미지를 포함해 치이카와 캐릭터의 모든 권리는 원작자 나가노에게 있어요. 권리자가 요청하면 바로 내릴게요.
