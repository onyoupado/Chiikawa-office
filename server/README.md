# 선택: 서버 프록시 예시

GitHub Pages는 정적 사이트라서 API 키를 안전하게 숨길 곳이 없어요. 그래서 기본 설정은 **데모 모드**예요. 실제 Claude를 쓰고 싶으면 아래 둘 중 하나를 고르세요.

1. **프롬프트 복사**: 화면의 '프롬프트 복사' 버튼으로 복사해서 Claude에 직접 물어보고, 받은 답을 '답 붙여 넣기'에 넣어요. 서버가 필요 없어요.
2. **직접 운영하는 서버 프록시**: 이 폴더의 `proxy.mjs`를 내 서버에서 실행해요. 이 서버만 API 키를 가지고, 브라우저는 관리자에게 받은 접속 코드로만 요청해요.

## 실행

```bash
cd server
npm install
ANTHROPIC_API_KEY=... ACCESS_TOKENS=친구1용-긴-무작위-코드,친구2용-긴-무작위-코드 \
ALLOWED_ORIGINS=https://내아이디.github.io npm start
```

그다음 저장소 루트의 `config.js`에 프록시 주소만 적어요 (키는 절대 적지 않아요).

```js
window.CHIIKAWA_CONFIG = { proxyUrl: "https://내-프록시-주소" };
```

## 들어 있는 보호 장치

| 항목 | 기본값 | 환경 변수 |
|---|---|---|
| 접속 코드(Bearer) 필수, 16자 이상 | 없으면 서버가 켜지지 않음 | `ACCESS_TOKENS` |
| 모델 고정·허용 목록 | `claude-opus-5-5` | `MODEL` |
| 출력 토큰 상한 | 4000 (최대 8000) | `MAX_TOKENS` |
| 요청 크기 | 64KB, 대화 12개·각 6000자 | – |
| 접속 코드별·IP별 속도 제한 | 분당 6회, 하루 100회 | `RATE_PER_MIN`, `RATE_PER_DAY` |
| 하루 전체 출력 토큰 상한(비용 상한) | 200,000 | `DAILY_OUTPUT_TOKEN_BUDGET` |
| 시간 초과 | 90초 | – |
| 로그 | 시각·접속 코드 해시·걸린 시간·토큰 수만 (대화 내용·키 기록 안 함) | – |

`ALLOWED_ORIGINS`(CORS)는 브라우저가 다른 사이트에서 부르지 못하게 하는 편의 기능일 뿐, **보호 수단이 아니에요**. curl 같은 도구는 CORS를 무시하니까 접속 코드를 꼭 비밀로 나눠 주고, 새면 바로 바꾸세요.

> 이 예시는 실제 Anthropic API로 호출해 보지 않았어요(미검증). 운영 전에 직접 시험해 주세요. 메모리 기반 속도 제한이라 서버를 여러 대 띄우면 공유되지 않아요.
